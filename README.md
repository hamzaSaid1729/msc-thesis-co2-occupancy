# MSc Thesis: CO2-Based Occupancy Prediction

This repository contains the source code and documentation for my Master's thesis on predicting building occupancy using CO2 sensor data and LSTM networks.

## Project Structure
- `data/` - Sample dataset files
- `src/` - Python source code (training and inference scripts)
- `thesis/` - Complete thesis documentation
- `outputs/` - Model outputs and results

## Contents
- LSTM regression model for occupancy count prediction
- LSTM classification model for occupancy level detection
- Complete thesis document with methodology and results
